# Hydra Obsidian Vault

This folder is an Obsidian-ready project map for Hydra.

## How to use

1. Open Obsidian.
2. Choose **Open folder as vault**.
3. Select `docs/obsidian`.
4. Start at [[00 - Start Here]].

## Why this exists

- Keeps architecture and code navigation in small linked notes
- Makes Obsidian Graph View useful through explicit `[[links]]`
- Gives AI agents a clear "where to look" path before editing

## Suggested workflow for humans and AI

1. Open [[00 - Start Here]].
2. Jump to [[02 - Where To Look]] for task-based navigation.
3. Open the relevant subsystem note.
4. Edit production files listed under each note.
